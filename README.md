## 📥 Commandes git pour sauvegarder le travail effectué
### Création d'un nouveau dépôt

```bash
git init
git add .
git commit -m "Premier commit"
git branch -M main
git remote add origin https://github.com/fduranddev/HTML_CSS.git
git push -u origin main
```

### Pousser le dépôt local vers GitHub

```bash
git remote add origin https://github.com/fduranddev/HTML_CSS.git
git branch -M main
git push -u origin main
```

### Personnaliser le dépôt 

```bash
git config user.name "Frédéric Durand"
git condig user.email "fduranddev@gmail.com"
```
## 🚀 Installation

```bash
git clone https://github.com/fduranddev/HTML_CSS.git
```
