Retour vers la page lien

Voici le chemin de retour

Valeur Description
_self _self est la valeur par défaut et exige que le lien s'ouvre dans le même onglet ou la même page.
_blank _blank permet d'ouvrir le lien hypertexte dans un nouvel onglet ou une autre fenêtre.
_parent _parent permet d'ouvrir le lien hypertexte dans la fenêtre parente.
_top Avec l'option _top, le document lié s'ouvrira dans une fenêtre entière.
<nom> Cette option vous permet d'ouvrir le document dans une iframe définie.
